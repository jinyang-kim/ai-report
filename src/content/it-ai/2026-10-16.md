## 언어·컴파일러: TypeScript 7 네이티브 컴파일러

- TypeScript 7 은 Go 로 재작성된 컴파일러(Project Corsa)이며, 마이크로소프트의 목표는 약 10배 빠른 빌드입니다. 초기 벤치마크로 VS Code 코드베이스 컴파일이 77.8초에서 7.5초로 줄었다고 소개됩니다. 이 수치는 초기 벤치마크이지 최종 프로덕션 결과가 아닙니다. [State of TypeScript 2026](https://devnewsletter.com/p/state-of-typescript-2026/)
- 마이그레이션 시 점검할 breaking change: `--strict` 기본화, ES5 타깃 제거, AMD/UMD/SystemJS 출력 제거, classic 모듈 해석 및 `baseUrl` 제거. [출처](https://devnewsletter.com/p/state-of-typescript-2026/)
- 7월 VoidZero 소식에서 `tsgolint` 버전 `v7.0.2000` 이 TypeScript 7.0.2 에 대응한다고 설명돼, 7.0 계열이 이미 패치 단계에 들어갔음을 알 수 있습니다. [VoidZero](https://voidzero.dev/posts/whats-new-jul-2026)

## 빌드 도구·린터: Vite·Rolldown·Oxc

[VoidZero 7월 소식](https://voidzero.dev/posts/whats-new-jul-2026) 기준으로 정리하면 다음과 같습니다.

- **Vite 8**: 출시 몇 달 만에 다운로드가 Vite 6·7 합계를 넘었습니다.
- **Oxlint 타입 인식 린팅 안정화**: ESLint + typescript-eslint 대비 대형 저장소에서 최대 18배 빠르고 typescript-eslint 규칙 61개 중 59개를 구현했다고 합니다.
- **Rolldown**: 대형 빌드 최대 메모리 사용 약 21% 감소.
- **Oxc**: 파서 3～5% 빨라졌고, 릴리스 바이너리의 디버그 정보 제거로 Darwin ARM64 npm 다운로드가 44.9% 줄었습니다.
- **Vitest 5.0.0-beta.7**: 브라우저 모드 커버리지 생성 단축, Temporal 객체 모킹 지원.
- **ViteConf**: 10월 15일 온라인(YouTube) 개최 예정으로 안내돼 있어, 관련 발표 내용은 후속 확인이 필요합니다.
