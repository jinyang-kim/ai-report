## 언어·컴파일러: TypeScript 7.1 베타

Daniel Rosenwasser 가 10월 20일 발표한 TypeScript 7.1 베타는 7월에 나온 Go 기반 네이티브 컴파일러(7.0)의 첫 후속 버전이다. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta) 보도에 따르면 베타는 계획보다 약 2주 늦었고, RC 와 정식판은 11월 말로 잠정 목표가 잡혀 있다.

- **컴파일러 API 복귀**: 7.0 에서 빠졌던 프로그래밍 API 가 `typescript/sync`, `typescript/async`, `typescript/fs`, `typescript/ast` 진입점으로 돌아온다. 정식 이후 7.x 내 하위 호환을 약속했다. ([InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta))
- **콘텐츠 매퍼**: `.vue`·`.svelte` 같은 비표준 파일을 TypeScript 가 가상 뷰로 볼 수 있게 하는 플러그인 지점이다. Vue Language Tools v4 알파는 이를 써서 별도 `vue-tsc` 바이너리를 없앤다. ([InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta))
- **언어 추가**: ambient 모듈 선언의 import attributes, WebAssembly 용 source phase imports, `Math.sumPrecise()`·`Error.isError()` 를 포함한 안정 `es2026` 타깃. ([InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta))

| 벤치마크 | 결과 |
|---|---|
| MUI 문서 (Microsoft) | 22.2초 → 11.9초, 메모리 약 절반 |
| Directus 관리자 앱 | 14.19초 → 3.10초 (`vue-tsc` 3 대비 4.6배) |
| NestJS 기반 35.3만 줄 (독립 테스트) | 7.1 2.76초 / 7.0 4.95초 / 구 컴파일러 12.42초 |

기사에서 알려진 문제로, 일부 에디터 워크플로에서 매퍼 설정 파일을 저장하면 언어 서버 재시작 전까지 타입이 낡은 채 남을 수 있다는 이슈가 열려 있다. 권고는 Vue·Svelte·Angular 프로젝트가 프레임워크 도구가 7.1 을 지원할 때까지 TypeScript 6 과 7 을 병행 설치하라는 것이다. ([InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta))

## AI 모델: 11월 출시 흐름

11월 모델 출시는 5일 전후와 중순에 몰렸다. 아래 내용은 서드파티 트래커 기준이며, 트래커끼리 날짜와 세부 수치가 다르므로 가격·벤치마크는 벤더 공식 발표로 재확인해야 한다.

- **Anthropic**: Claude Fable 5.2(유료·API)와 접근이 제한된 Mythos 5.2. [ThursdAI](https://thursdai.news/releases/2026-11)는 11월 12일, [nocode.mba](https://www.nocode.mba/ai-release-tracker/2026/11)는 Mythos 5.2 를 11월 9일(제한 접근)로 적는다. ThursdAI 는 가격을 입력/출력 백만 토큰당 $8/$40, Artificial Analysis 지수 1위(65)로 소개했다.
- **Google**: Gemini 4 Hydrogen(11월 12일, 빠른 모델)은 두 트래커가 모두 적는다. ThursdAI 는 Gemini 4 Carbon GA 와 11월 30일까지 $2/$10 도입가를 전하지만 nocode.mba 에는 Carbon 항목이 없다.
- **OpenAI**: ThursdAI 는 GPT-6 Cyber(제한 프로그램)와 Images 2.6 을, nocode.mba 는 11월 17일 GPT-6.2 Astra·Sol 을 기록했다.
- **오픈 웨이트**: ThursdAI 에 따르면 Moonshot 의 Kimi K3.1 Pro 는 2.8T 파라미터 MoE(활성 104B, 컨텍스트 1M)이고 $4/$20 로 책정됐다. Ricursive 의 Ripple-65B Preview 는 Apache 2.0 이다.
- **그 밖에**: nocode.mba 는 Alibaba Qwen4-Max(11월 16일), Microsoft MAI Code 2(11월 17일)도 올렸다.

## 실무 시사점

- 컴파일러 API 에 의존하는 도구(린터, 코드 생성기, 프레임워크 플러그인)는 새 진입점으로 포팅하고 정식 전에 누락 API 를 보고하는 편이 좋다.
- 모델 선택은 도입가 종료(Gemini 4 Carbon 11월 30일) 같은 가격 변동과 벤더 자체 보고 벤치마크의 한계를 감안해 자체 평가셋으로 검증하는 것이 안전하다.
