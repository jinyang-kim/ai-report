## AI 모델 — 10월 출시 흐름

같은 페이지는 집계 목록 밖의 보도도 전합니다. [Reflection AI 의 Beam(Apache 2.0 오픈 웨이트), NVIDIA Dory 1.0-4B(추론 깊이 조절형), Mistral Large 4(1조 파라미터 멀티모달, 10월 9일 보도), MiniMax M3.1 Flash(에이전트 비용 약 70% 절감 보도)](https://af.net/realtime/confirmed-ai-model-releases-for-october-2026/) 등입니다.

패턴은 두 가지입니다. 하나는 활성 파라미터를 줄인 MoE 계열(A12B, A2B)과 4B급 소형 모델처럼 **추론 비용을 낮추는 설계**, 다른 하나는 Apache 2.0 같은 **허용적 라이선스의 오픈 웨이트** 확산입니다. 다만 벤치마크 점수·가격은 이 출처에 없어 비교하지 않았고, 개별 모델 수치는 각 제공사 공식 발표로 확인해야 합니다.

## 언어·컴파일러 — TypeScript 7 이후

TypeScript 7 은 Go 로 포팅한 네이티브 컴파일러(Project Corsa)입니다. 사전 개요 자료에 따르면 [VS Code 코드베이스 빌드가 약 77.8초에서 7.5초로 줄었다는 초기 벤치마크](https://devnewsletter.com/p/state-of-typescript-2026/)가 있으며, 독립 검증은 되지 않은 수치입니다. 같은 자료는 다음 호환성 주의점을 짚습니다.

- 프로그래밍 API 가 달라져 typescript-eslint 등은 새 메이저 버전이 필요하다.
- strict 기본값, ES5 타깃 제거, AMD/UMD/SystemJS 출력 제거, `baseUrl` 제거 같은 브레이킹 체인지가 있다.
- 플러그인용 TS 6.x 와 빌드용 `tsgo` 를 병행하는 하이브리드 구성이 제안된다.

실제 7.0 계열이 나왔다는 정황은 VoidZero 7월 리캡에 있습니다. [tsgolint 버전이 TypeScript 7.0.2 에 맞춰 v7.0.2000 으로 매겨진다](https://voidzero.dev/posts/whats-new-jul-2026)고 설명합니다.

## 빌드 도구·린터

[Oxlint 의 타입 인식 린팅이 7월 22일 안정화](https://voidzero.dev/posts/whats-new-jul-2026)됐습니다. 프로젝트 벤치마크 기준 대형 저장소에서 typescript-eslint 를 쓴 ESLint 보다 최대 18배 빠르고, typescript-eslint 규칙 61개 중 59개를 구현합니다. 엔진 tsgolint 가 TypeScript 릴리스를 그대로 따라가는 구조라, 컴파일러 업그레이드 주기가 린트 도구 선택에도 영향을 줍니다.

같은 리캡에서 [Vite 8 다운로드는 출시 몇 달 만에 Vite 6·7 합계를 넘었고](https://voidzero.dev/posts/whats-new-jul-2026), Rolldown 은 큰 빌드에서 최대 메모리를 약 21% 줄였으며, Vitest 5.0.0-beta.7 이 나왔습니다. [ViteConf 는 10월 15일 온라인 무료 행사](https://voidzero.dev/posts/whats-new-jul-2026)로 예고됐으나, 이번 조사에서는 행사 내용을 확인하지 못했습니다.

## 실무 시사점

- 모델 선택은 최고 성능보다 **활성 파라미터·라이선스·온디바이스 가능 여부**로 기준이 이동하고 있습니다.
- TypeScript 7 도입 전 CI 에서 `@typescript/native-preview` 로 먼저 돌려 보고, [서드파티 도구의 API 호환성을 점검](https://devnewsletter.com/p/state-of-typescript-2026/)하는 편이 안전합니다.
- 린터를 교체한다면 Oxlint 타입 인식 모드가 후보이며, 미구현 규칙 2개가 팀 규칙에 포함되는지 먼저 확인하세요.
