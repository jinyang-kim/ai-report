## 개발 도구 생태계 — OpenAI가 Cursor에서 손을 뗀다

OpenAI가 코딩 툴 **Cursor**(개발사 Anysphere)에 대한 모델 공급을 중단하겠다고 8월 29일 통보했습니다.
제안된 차단 시점은 **11월 12일**입니다. 계기는 SpaceX 가 8월 14일 Anysphere 를 약 **600억 달러**에
인수한 일입니다. OpenAI 계약에는 지배구조가 바뀌면 계약을 재검토할 수 있는 change-of-control
조항이 있었고, 이번에 그 조항을 발동했습니다.

OpenAI 가 공식적으로 든 이유는 신뢰입니다. 일론 머스크가 이끄는 다른 회사 xAI 가 OpenAI 모델을
**distillation**(증류) 기법으로 학습에 활용해 이용약관을 위반했다고 머스크 본인이 선서 증언한 전례가
있어, SpaceX 산하가 된 Cursor 가 약관을 지킬지 확신할 수 없다는 것입니다.

### 실무 영향은 제한적

- Cursor 트래픽 중 OpenAI 모델 비중은 **약 5%** 로 알려져, 대다수 사용자에게 체감 영향은 작습니다.
- 그래도 OpenAI 모델을 Cursor 안에서 계속 쓰고 싶다면 **개인 API 키를 직접 연결**하거나 Azure·AWS
  Bedrock 같은 게이트웨이를 경유하는 우회로가 남아 있습니다.
- **Anthropic** 은 Cursor 내 Claude 지원을 위해 컴퓨팅을 늘리겠다고 밝혔습니다 — 주력 모델 공급사
  지위를 굳히는 모양새입니다.
- Cursor 는 자체 모델 **Composer 2.5** 를 오픈 웨이트 체크포인트 기반으로 학습해 프론티어 랩
  의존도를 이미 낮춰오던 중이었습니다.

### 읽을 것

빅테크 인수·자본 관계가 **모델 공급 계약의 지속 가능성**에 직접 영향을 준다는 사례입니다. AI 코딩
툴을 프로덕션에 깊게 물려 쓰는 팀이라면, 특정 모델 제공사 하나에 하드 의존하기보다 API 키를 직접
관리하거나 대체 경로를 미리 확인해 두는 편이 안전합니다.

## 언어·컴파일러 — TypeScript 7.0, 정식 GA 확정

TypeScript 7.0 이 **정식 GA(General Availability)** 로 확정됐습니다. 핵심은 컴파일러를 **Go 로
새로 작성한 네이티브 구현**으로 교체했다는 점입니다. 기존 TypeScript 로 작성된 컴파일러 구조를
그대로 옮기는 데 초점을 맞춰, 동작 동일성을 유지하면서 속도를 끌어올렸습니다.

체감 효과는 벤치마크 수치로 확인됩니다. **VS Code 소스 기준 풀빌드**가 TypeScript 6 의 125.7초에서
10.6초로, **11.9배** 단축됐습니다. InfoQ 는 전반적으로 **8~12배** 구간의 개선을 보고했습니다.

### 도입 판단

- 대형 모노레포에서 타입체크·빌드 시간이 실제 병목이라면 우선순위를 올릴 만합니다.
- 기존 `typescript` 패키지와 나란히 설치해 먼저 빌드 시간만 재보고 전환 여부를 판단하는 점진적
  접근이 여전히 유효합니다. GA 라도 대형 코드베이스는 tsconfig·플러그인 호환성을 먼저 점검하세요.

## AI 인프라 — Hugging Face, Kernels 허브를 신뢰 게시자 모델로 개편

Hugging Face 가 커스텀 GPU 커널을 패키징·배포·로딩하는 **Kernels** 프로젝트를 개편했습니다.
Hub 안에 커널 전용 리포지터리 타입을 두어 지원 가속기·OS·백엔드 버전 같은 메타데이터를 통해
검색성을 높인 것이 골자입니다.

바뀐 점 세 가지입니다.

- **보안** — 기본값이 커뮤니티가 검증한 조직(**trusted publisher**)이 게시한 커널만 로드하도록
  바뀌었습니다. 임의 소스의 커널이 무심코 실행되는 경로를 차단합니다.
- **재현성** — **Nix 기반 hermetic 빌드**와 커널에 내장되는 소스 Git SHA 로 "같은 커널을 다시
  빌드하면 같은 결과가 나온다"를 보장합니다.
- **역할 분리** — `kernels` 라이브러리는 로딩·준비만 담당하고, 빌드는 `kernel-builder` 로 넘겨
  각 도구를 더 가볍고 전문화된 형태로 나눴습니다.

### 실무 영향

Flash Attention 같은 어텐션 구현을 직접 컴파일하지 않고 Hub 에서 커널을 받아 꽂는 방식이 이미
가능했는데, 이번 개편으로 그 경로의 **공급망 신뢰성**이 강화됐습니다. 자체 추론 서버에 커스텀
커널을 쓰는 팀이라면 신뢰 게시자 목록과 Nix 빌드 재현 여부를 점검해 볼 시점입니다.
