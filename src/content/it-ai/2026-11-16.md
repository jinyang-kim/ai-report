## 언어·컴파일러: TypeScript 7.1 베타

[InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)에 따르면 마이크로소프트는 10월 20일 7.1 베타를 공개했고, 일정은 계획보다 약 2주 늦었습니다. RC 와 정식 릴리스는 11월 말로 잠정 계획돼 있습니다.

- **컴파일러 API 복원**: 7.0 에서 빠졌던 API 가 `typescript/sync`, `typescript/async`, `typescript/fs`, `typescript/ast` 등 용도별 진입점으로 돌아왔고, 기존 "unstable" 접두어는 제거됐습니다. 정식 이후 7.x 내 하위 호환을 약속했습니다.
- **Content mapper**: `.vue`, `.svelte` 같은 비표준 파일을 TypeScript 가 가상 뷰로 보게 하는 플러그인 지점입니다. 별도 프로세스로, 활성화했을 때만 동작합니다. Vue Language Tools v4 알파는 이를 이용해 별도 `vue-tsc` 바이너리를 없앴습니다.
- **언어 추가**: 앰비언트 모듈 선언의 import attributes, WebAssembly 용 source phase imports, `Math.sumPrecise()`·`Error.isError()` 를 포함한 안정 `es2026` 타깃.
- **성능**: Directus 관리자 앱(Vue 컴포넌트 581개)의 타입 검사가 14.19초에서 3.10초로(`vue-tsc` 3 대비 4.6배), NestJS(35만 줄) 독립 테스트에서 7.1 베타 2.76초 대 7.0 4.95초 대 구 컴파일러 12.42초였습니다. 7.0 의 메모리 회귀도 되돌렸다고 합니다([InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)).
- **알려진 이슈**: 감시 중인 mapper 설정 파일을 저장하면 언어 서버를 재시작하기 전까지 타입이 갱신되지 않는 사례가 보고돼 열려 있습니다.

**실무 팁**: Vue·Svelte·Angular 프로젝트는 프레임워크 도구가 7.1 을 지원할 때까지 TypeScript 6 과 7 을 나란히 두라는 것이 기사의 권고입니다. TypeScript 5 사용자는 6을 거쳐 7로 올라가는 경로를 따르라고 합니다.

## 빌드·개발 도구: GitHub Universe 이후 Copilot

[GitHub Changelog 10월](https://github.blog/changelog/month/10-2026/)에 10월 28일자로 묶여 공개된 항목 중 실무 영향이 큰 것입니다.

- **Copilot Fusion GA**: 작업별로 모델을 골라 조율하며, 온디바이스 모델과 클라우드 모델 사이를 라우팅하는 로컬 모델 지원은 실험 프리뷰입니다.
- **GitHub Agentic Workflows GA**: 추론 기반 작업을 자동화하는 오픈소스 프로젝트가 정식 출시됐습니다.
- **Copilot 앱·IDE**: 멀티 레포 작업, 팀 선호도·레포 규칙·스킬·커스텀 지침 반영, 공유 Copilot Automations, JetBrains 의 Fusion 오케스트레이션과 로컬 샌드박스.
- **보안**: Dependabot 도달 가능성 분석(취약 코드 경로의 실제 사용 여부로 알림 우선순위화)과 Copilot 앱 안의 코드 스캐닝 보안 확장(퍼블릭 프리뷰).
- **엔터프라이즈**: 자격이 되는 GitHub Enterprise 에 사용자별로 Copilot 이 포함됩니다. 플러그인 기본값과 엔터프라이즈 제어도 GA 입니다.
- **네트워크**: 메타 API 의 `hooks` 필드에 웹훅 전달 IP 대역이 추가돼, 정적 방화벽 허용 목록을 쓰는 팀이 참고할 만합니다.

## 패턴 정리

1. **모델 선택의 자동화**: Fusion 처럼 도구가 모델을 고르는 구조가 늘면서, 개별 모델 순위보다 라우팅 정책과 비용 상한 설정이 더 중요해집니다.
2. **가격 변동성**: 도입가·한시 무료(SWE-2 Flash 는 일부 플랜에서 11월 30일까지 무료)가 많아 월말 이후 비용 재계산이 필요합니다.
3. **네이티브 컴파일러 시대의 생태계 호환**: 속도는 확보됐고, 이제 쟁점은 API 호환과 Vue·Svelte 같은 비표준 파일 지원입니다.

> 속도 경쟁이 끝나가는 자리에서 승부처는 호환성과 오케스트레이션으로 옮겨가고 있습니다.
