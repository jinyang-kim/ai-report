## 언어·컴파일러: TypeScript 7.1 베타

Go 기반 네이티브 컴파일러가 7월에 7.0으로 나온 뒤 첫 업데이트인 7.1 베타가 10월 20일 발표됐다. 계획보다 약 2주 늦었다. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)

- **컴파일러 API 복원**: 7.0에서 빠졌던 API가 `typescript/sync`, `typescript/async`, `typescript/fs`, `typescript/ast` 진입점으로 나뉘어 돌아왔고 `unstable` 접두사는 사라졌다. 정식 이후 7.x 동안 하위 호환을 유지한다고 한다. 7.0 때문에 TypeScript 6에 머물던 Volar, Svelte, Astro, ts-morph 같은 도구가 대상이다. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)
- **콘텐츠 매퍼**: `.vue`·`.svelte` 같은 파일을 TypeScript에 가상 뷰로 보여 주고 오류를 원본 줄로 되돌려 매핑하는 플러그인 지점이다. 별도 프로세스로 돌며 옵트인할 때만 실행된다. Vue Language Tools v4 알파는 이를 써서 `vue-tsc` 바이너리를 `@vue/content-mapper` 로 대체한다. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)
- **언어 추가**: 앰비언트 모듈 선언의 import attributes, WebAssembly용 source phase imports, `Math.sumPrecise()`·`Error.isError()` 를 포함하는 안정 `es2026` 타깃. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)

### 실무 시사점

- 릴리스 후보와 정식 빌드는 11월 말로 잠정 계획돼 있으나 확정은 아니다. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)
- Vue·Svelte·Angular 프로젝트는 프레임워크 도구가 7.1 빌드를 내놓을 때까지 TypeScript 6과 7을 나란히 설치해 두는 편이 안전하다. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)
- 알려진 이슈: 매퍼가 감시하는 설정 파일을 저장하면 언어 서버를 재시작할 때까지 타입이 낡은 채로 남는 경우가 보고됐고, 아직 열려 있다. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)
- 배경으로, 3월의 TypeScript 6.0은 `strict` 기본 true, `types` 기본 `[]`, `module` 기본 `esnext` 등 기본값을 조였다. 5에서 올라온다면 6을 거쳐 7로 가야 한다. [Node Weekly #617](https://nodeweekly.com/issues/617)

- **로컬 추론 도구**: Apache 2.0 의 inferd 는 32GB Mac Mini 에서 Qwen 3.8 27B 로 에이전트 16개를 동시에 돌려 총 1,000 tokens/sec 이상을 보였다고 한다. [ThursdAI](https://thursdai.news/releases/2026-11)
- **도구 소식**: Claude Code 2.1.317 은 특정 기존 게임 재현 금지 규칙을 장르 설명에 한해 완화했다. Apple 은 iOS 27.3 베타에서 임의 앱의 App Intents 를 Siri 가 쓰는 개발자 프리뷰를 냈다. [ThursdAI](https://thursdai.news/releases/2026-11)
