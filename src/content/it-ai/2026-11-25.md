## 언어·컴파일러: TypeScript 7.1 베타

TypeScript 7.1 베타는 2026년 10월 20일 발표됐고, 계획보다 2주 늦었다. 릴리스 후보와 정식 빌드는 11월 말로 잠정 계획돼 있다. ([InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta))

- **컴파일러 API 복원**: 7.0에서 프로그래밍 API가 빠져 Volar, Svelte, Astro, ts-morph 같은 도구가 TypeScript 6에 머물렀다. 7.1은 이를 `typescript/sync`, `typescript/async`, `typescript/fs`, `typescript/ast` 진입점으로 나누고 `unstable` 접두사를 없앴으며, 정식 이후 7.x 내 하위 호환을 목표로 한다. ([InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta))
- **증분 편집·콘텐츠 매퍼**: 재사용 가능한 스냅샷과, `.vue`·`.svelte` 같은 비표준 파일을 가상 뷰로 보여주는 콘텐츠 매퍼 플러그인 지점이 추가됐다. ([InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta))
- **언어 추가**: 앰비언트 모듈 선언의 import attributes, WebAssembly용 source phase imports, 안정화된 `es2026` 타깃. ([InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta))

| 사례 | 결과 |
| --- | --- |
| MUI 문서 빌드 | 22.2초 → 11.9초, 메모리 약 절반 |
| Directus 관리 앱 타입 검사 | 14.19초 → 3.10초 (`vue-tsc` 3 대비 4.6배) |
| NestJS 35만 줄(독립 테스트) | 7.1 베타 2.76초 / 7.0 4.95초 / 구 컴파일러 12.42초 |

알려진 이슈로, 매퍼가 감시하는 설정 파일을 저장하면 언어 서버를 재시작할 때까지 타입이 갱신되지 않을 수 있다는 버그가 열려 있다. ([InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta))

## 빌드 도구: Vite 8과 Rolldown·Oxc

7월 VoidZero 소식에 따르면 Vite 8의 다운로드는 출시 몇 달 만에 Vite 6과 7을 합친 것보다 많고, Vite 전체로는 주간 1.5억 건 이상이다. Rolldown은 큰 빌드의 최대 메모리를 약 21% 줄였고, Oxc의 타입 인식 린팅은 안정화되어 대형 저장소에서 ESLint+typescript-eslint보다 최대 18배 빠르며 typescript-eslint 규칙 61개 중 59개를 구현했다. ([VoidZero](https://voidzero.dev/posts/whats-new-jul-2026)) 다만 이 자료는 7월 기준이라 11월의 신규 릴리스는 확인하지 못했다.
