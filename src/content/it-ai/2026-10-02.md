## 언어·컴파일러

TypeScript 최신 안정판은 7.0.2(2026년 7월 8일)다. 컴파일러와 언어 서비스를 Go 네이티브 바이너리로 다시 썼고, 마이크로소프트는 TypeScript 6.0 대비 전체 빌드가 대체로 8～12배 빨라졌다고 밝혔다. VS Code 코드베이스 타입 검사는 125.7초에서 10.6초로 줄었다. [Wikipedia](https://en.wikipedia.org/wiki/TypeScript)

실무 유의점: 7.0 은 안정적인 프로그램 API 없이 출시됐고 7.1 에서 도입할 계획이다. Vue·Angular·Svelte 등 컴파일러 API 에 의존하는 도구는 그 전까지 영향을 점검해야 한다. [Wikipedia](https://en.wikipedia.org/wiki/TypeScript)

## 빌드 도구

Vite 8(2026년 3월 12일)은 기존 이중 번들러 구조를 Rust 기반 Rolldown 으로 통합했다. 빌드가 최대 10～30배 빨라졌다고 하며, Linear 는 46초에서 6초, Beehiiv 는 64%, Mercedes-Benz.io 는 최대 38% 단축을 보고했다. Node.js 20.19+ / 22.12+ 가 필요하고, 설치 크기는 Vite 7 보다 약 15MB 크다. [Vite](https://vite.dev/blog/announcing-vite8)
