## 언어·컴파일러: TypeScript 7.1 베타

[InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)에 따르면 Microsoft 는 10월 20일 TypeScript 7.1 베타를 공개했고, 기사는 11월 6일에 게재됐다. 7.0 에서 빠졌던 컴파일러 API 가 복원된 것이 핵심이다.

- **컴파일러 API 복원**: `typescript/sync`, `typescript/async`, `typescript/fs`, `typescript/ast` 같은 진입점으로 나뉘고 `unstable` 접두어가 제거됐다. 7.0 때문에 TypeScript 6 에 머물던 Volar, ts-morph, Astro 같은 도구가 대상이다. 정식 출시 후 7.x 내에서는 하위 호환을 유지한다고 한다.
- **Content mapper**: `.vue`, `.svelte` 같은 파일을 TypeScript 가 가상 뷰로 볼 수 있게 하는 플러그인 지점이다. 별도 프로세스로 돌며 옵트인할 때만 실행된다. Vue Language Tools v4 알파는 이를 써서 `vue-tsc` 별도 바이너리를 `tsc` 안에서 도는 mapper 로 대체한다.
- **언어 추가**: ambient 모듈 선언의 import attributes, WebAssembly 용 source phase imports, `Math.sumPrecise()`·`Error.isError()` 를 포함한 안정 `es2026` 타깃.
- **성능**: Microsoft 의 MUI 문서 벤치마크는 22.2초에서 11.9초로, 메모리는 약 절반으로 줄었다. VS Code 같은 대형 코드베이스는 약 1.2배 개선에 그친다. 독립 측정(NestJS, 35.3만 줄)은 7.1 베타 2.76초, 7.0 4.95초, 기존 컴파일러 12.42초이며 7.0 의 메모리 회귀도 되돌렸다. Directus 관리자 앱(Vue)은 `vue-tsc` 3 대비 4.6배(14.19초에서 3.10초) 빨라졌다.
- **알려진 문제**: mapper 가 감시하는 설정 파일을 저장하면 언어 서버를 재시작할 때까지 타입이 갱신되지 않는 이슈가 열려 있다.

RC 와 정식 빌드는 11월 말로 잠정 계획돼 있으나, 베타가 일정보다 약 2주 늦었다. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)
