## 언어·컴파일러: TypeScript 7.1 베타

Go 기반 네이티브 컴파일러의 첫 후속 업데이트인 TypeScript 7.1 베타가 2026년 10월 20일 공개됐다. 7.0은 2026년 7월에 나왔고, 일정은 약 2주 늦어졌다. 릴리스 후보와 안정판은 11월 말로 잠정 계획돼 있다. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)

- **컴파일러 API 복원**: 7.0에서 빠졌던 API가 `typescript/sync`, `typescript/async`, `typescript/fs`, `typescript/ast` 진입점으로 나뉘어 돌아왔고 `unstable` 접두어가 사라졌다. 7.0 때문에 TypeScript 6에 머물던 Volar, Svelte, Astro, ts-morph 같은 도구에 중요한 변화다. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)
- **content mapper**: `.vue`·`.svelte` 같은 비표준 파일을 TypeScript에 가상 뷰로 보여 주는 공식 플러그인 지점이다. Vue Language Tools v4 알파는 이를 써서 별도 `vue-tsc` 바이너리를 없앴다. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)
- **언어 추가**: ambient module 선언의 import attributes, WebAssembly용 source phase imports, 안정 `es2026` 타깃(`Math.sumPrecise()`, `Error.isError()` 포함). [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)

| 벤치마크 | 이전 | 7.1 베타 |
| --- | --- | --- |
| Directus 관리자 앱(Vue 581개, TS 882개) | 14.19초 (`vue-tsc` 3) | 3.10초 (약 4.6배) |
| MUI 문서 | 22.2초 | 11.9초 (메모리 약 절반) |
| NestJS 35.3만 줄(독립 테스트) | 7.0 4.95초 / 구 컴파일러 12.42초 | 2.76초 |

VS Code 쪽 개선은 약 1.2배 수준이다. 7.0에서 생긴 메모리 회귀도 7.1에서 되돌려졌다. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta) 알려진 문제로, mapper가 감시하는 설정 파일을 저장하면 언어 서버를 재시작할 때까지 타입이 낡은 채로 남을 수 있다(이슈 65084, 미해결).

**실무 시사점**: TypeScript 5 사용 팀은 6을 거쳐 7로 가라는 권고가 있다. Vue·Svelte·Angular 프로젝트는 프레임워크 도구가 7.1을 지원할 때까지 6과 7을 나란히 설치해 두는 편이 안전하다. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)

TypeScript는 속도 이득을 얻은 대신 생태계 도구가 따라오는 시간이 필요한 단계다. [State of TypeScript 2026](https://devnewsletter.com/p/state-of-typescript-2026/) 모델 쪽에서는 범용 최상위 경쟁 외에 저비용 코딩, 보안, 오픈 웨이트 같은 특화 축이 뚜렷해졌다. 벤치마크 수치는 벤더 보고라 직접 검증한 뒤 판단하는 것이 좋다.
