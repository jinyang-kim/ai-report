## AI 모델 — 10월 중순 출시 흐름

BenchLM 집계 기준 10월에 16개 제공사에서 20건의 모델이 출시됐다. 다만 집계 페이지가 이름을 공개한 것은 일부뿐이며 가격 정보는 없다. ([AF.NET](https://af.net/realtime/confirmed-ai-model-releases-for-october-2026/))

| 모델 | 제공사 | 출시일 | 특징 |

| LFM2.5-24B-A2B | Liquid AI | 10월 13일 | 온디바이스 에이전트용 |
| Grok Voice 3.0 | xAI | 10월 14일 | 대량 통화용 음성-음성 모델 |
| Muse Spark | Meta | 10월 15일 | 세부 사양 미공개 |
| Nemotron 3.5 Super VL 120B A12B | NVIDIA | 10월 15일 | 멀티모달 |
| Jais 3 | IFM | 10월 15～16일 | 512K 토큰 컨텍스트의 아랍어 오픈 모델 6종(날짜는 출처별로 상이) |
| DeepSeek V4.1-Flash-1017 | DeepSeek | 10월 17일 | 속도·벤치마크 개선 |

**패턴:** 범용 프런티어 경쟁보다 음성, 온디바이스, 지역 언어 특화 모델처럼 용도가 쪼개진 출시가 눈에 띈다. 모델 이름의 `120B A12B`, `24B-A2B` 표기는 전체 파라미터 대비 활성 파라미터가 작은 희소(MoE)형 구성임을 시사하지만, 이는 이름에서의 추정이며 출처가 사양을 확인해 주지는 않는다. Gemini 4 등 대형 출시는 공식 발표가 확인되지 않아 다루지 않는다.

## 빌드·린트 도구 — 네이티브 전환의 실무화

VoidZero 7월 소식에 따르면 Oxlint 의 타입 인식 린팅이 7월 22일 안정화됐고, 대형 저장소에서 ESLint+typescript-eslint 대비 최대 18배 빠르다. tsgolint 는 typescript-eslint 규칙 61개 중 59개를 구현했다. ([VoidZero](https://voidzero.dev/posts/whats-new-jul-2026))

- **Vite:** Vite 8 의 다운로드가 출시 몇 달 만에 Vite 6·7 합계를 넘었고, Vite 전체는 주간 1억 5천만 건 이상이다.
- **Rolldown:** 큰 빌드의 최대 메모리 사용량이 약 21% 줄었다. Angular CLI 는 Rolldown 을 기본 청크 최적화기로 채택해 Rollup 을 대체했다.
- **Oxc:** 디버그 정보 제거로 npm 다운로드 크기가 44.9% 줄었고 파서는 3～5% 빨라졌다.
- **Vitest:** 5.0.0-beta.7 에서 전반적 속도 개선과 Temporal 목 지원이 들어갔다.
- **행사:** ViteConf 가 10월 15일 온라인으로 열렸다.

## 언어·컴파일러 — TypeScript 7 (Go 포팅) 점검

1월 기사 기준으로 TypeScript 7 은 컴파일러를 Go 로 포팅한 "Corsa" 이며, 초기 벤치마크는 VS Code 코드베이스 컴파일 약 77.8초에서 약 7.5초로 줄었다. 기본 `--strict`, ES5 타깃 제거, 클래식 node 모듈 해석 제거 등이 예고된 브레이킹 체인지다. ([State of TypeScript 2026](https://devnewsletter.com/p/state-of-typescript-2026/)) 이 수치는 1월 시점의 초기 값이며 최종 출시 버전의 공식 확인은 이번 조사에서 하지 못했다. 위 VoidZero 글이 `v7.0.2000` 같은 TypeScript 7.0.x 연동 버전을 언급하는 점으로 보아 7.x 는 이미 배포 단계로 보이나, 프로그래밍 API 공백과 린터·플러그인 호환성은 도입 전에 점검해야 한다.

- 온디바이스·희소 모델은 사양이 공식 문서로 확인된 뒤 가격·지연 시간 기준으로 비교하는 것이 안전하다.
