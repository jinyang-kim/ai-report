## 9월 플래그십 러시 복기

같은 [타임라인](https://llmgateway.io/timeline/2026)상 9월에는 다음이 이어졌다.

- **Anthropic**: Claude Fable 5.1(9/1), Claude Opus 5.5(9/22), Claude Sonnet 5.5(9/28)
- **OpenAI**: GPT-6 Astra(9/3), GPT-6 Sol·Luna(9/22), GPT-6.1 Sol(9/29)

OpenAI 는 한 달 안에 6.0 에서 6.1 로 올렸다. 모델 교체 주기가 주 단위로 짧아졌으므로, 실무에서는 특정 모델명을 하드코딩하기보다 설정으로 분리하고 평가 세트를 갖춰 두는 편이 안전하다.

## 언어·컴파일러 — TypeScript 6 에서 7 로

[State of TypeScript 2026](https://devnewsletter.com/p/state-of-typescript-2026/)은 TypeScript 6.0 을 JS 기반 컴파일러의 마지막 릴리스, 7.0 을 Go 기반("Corsa") 컴파일러로 정리한다. 같은 글이 인용한 수치는 다음과 같다(2차 요약이므로 공식 블로그 확인 필요).

- 컴파일 약 5～10배 빠름, 에디터 시작 약 8배, 메모리 약 50% 절감
- VS Code 컴파일 7.5초 vs 77.8초
- 7.0 브레이킹 체인지: `--strict` 기본 활성, `--target ES5` 제거, AMD/UMD/SystemJS 출력 제거, `baseUrl` 제거

[Reactiflux 7월 대화록](https://www.reactiflux.com/transcripts/tmir-2026-07)은 TypeScript 7 이 공개됐고 프로그래매틱 API 가 사실상 없어졌다고 전한다. API 에 의존하는 린터·코드 생성 도구는 호환성 점검이 필요하다. 하이브리드로 플러그인은 6.x `tsc`, 빌드는 `tsgo` 를 쓰는 방식이 제안되고 있다.

## 빌드·린트 도구

VoidZero 의 [7월 소식](https://voidzero.dev/posts/whats-new-jul-2026)은 Oxlint 의 타입 인식 린팅이 안정화되고 속도와 규칙 수가 개선됐다고 밝힌다. 네이티브 컴파일러 전환(TypeScript 7)과 Rust 기반 린터의 결합이 "JS 로 만든 JS 도구" 에서 벗어나는 흐름의 축이다.

## 시사점

> 모델은 한 달에 두 번 바뀌고, 컴파일러는 10년 만에 바뀐다. 둘 다 추상화 계층을 두는 팀이 덜 흔들린다.

- 모델: 플래그십 대신 Haiku·Flash 급으로 비용을 낮출 수 있는지 자체 평가 세트로 재측정할 시점이다.
- 도구: CI 에서 `tsgo` 를 병행 실행해 7.0 브레이킹 체인지를 미리 확인해 두자.
- 이 리포트의 모델 정보는 집계 사이트 기준이라 성능·가격은 각 공급자 공식 발표로 재확인해야 한다.
