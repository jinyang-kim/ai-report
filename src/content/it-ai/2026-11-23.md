## 언어·컴파일러: TypeScript 7.1 베타

TypeScript 7.1 베타는 10월 20일 공개됐고, [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)가 11월 6일 이를 다뤘다. 핵심은 **7.0에서 빠졌던 프로그래매틱 컴파일러 API의 복원**이다. 이 공백 때문에 Volar, Svelte, Astro, ts-morph 같은 도구가 TypeScript 6에 머물러 있었다. ([InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta))

- API는 `typescript/sync`, `typescript/async`, `typescript/fs`, `typescript/ast` 등 용도별 진입점으로 나뉘었고 "unstable" 접두사가 사라졌다. 정식 출시 후 7.x 내에서 하위 호환을 유지하겠다고 한다.
- **콘텐츠 매퍼**는 `.vue`·`.svelte` 같은 비표준 파일을 가상 뷰로 보여 주고 원본 위치로 되매핑하는 공식 확장 지점이다. 별도 프로세스로 돌며 옵트인 시에만 실행된다.
- 언어 측면에서는 ambient 모듈 선언의 import attributes, WebAssembly용 source phase imports, `Math.sumPrecise()`·`Error.isError()`를 포함한 안정 `es2026` 타깃이 추가됐다.

| 벤치마크 | 결과 |
| --- | --- |
| MUI 문서(Microsoft) | 22.2초 → 11.9초, 메모리 약 절반 |
| NestJS 35.3만 줄(독립 측정) | 7.1 베타 2.76초 / 7.0 4.95초 / 구 컴파일러 12.42초 |
| Directus(Vue) + 콘텐츠 매퍼 | 14.19초 → 3.10초, `vue-tsc` 3 대비 4.6배 |

VS Code 같은 대형 코드베이스는 1.2배 안팎이라 이득이 프로젝트마다 다르다. 일정은 계획상 11월 말 RC·정식이며, 베타 자체가 계획보다 약 2주 늦었으므로 확정이 아니라 목표로 봐야 한다. ([InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta))
