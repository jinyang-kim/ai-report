## 언어·컴파일러: TypeScript 7.1 베타

Microsoft 는 10월 20일 TypeScript 7.1 베타를 공개했고, InfoQ 가 11월 6일 이를 정리했습니다. 베타는 일정보다 약 2주 늦었고, RC 와 정식 릴리스는 11월 말로 잠정 계획되어 있습니다. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)

- **컴파일러 API 복원**: 7.0 에서 프로그래매틱 API 가 빠져 Volar, ts-morph, Astro 같은 도구가 TypeScript 6 에 묶여 있었습니다. 7.1 은 `typescript/sync`, `typescript/async`, `typescript/fs`, `typescript/ast` 로 진입점을 나누고 `unstable` 접두사를 없앴으며, 정식 이후 7.x 내 하위 호환을 약속합니다. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)
- **Content mapper**: `.vue`·`.svelte` 같은 비표준 파일을 가상 뷰로 보여주고 오류를 원본 줄로 매핑하는 플러그인 지점입니다. 별도 프로세스로 실행되며 옵트인 시에만 동작합니다. Vue Language Tools v4 알파는 이를 사용해 `vue-tsc` 바이너리를 없앱니다. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)
- **언어 추가**: ambient 모듈 선언의 import attributes, WebAssembly 용 source phase imports, 안정적인 `es2026` 타깃. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)

| 측정 | 결과 | 주체 |
| --- | --- | --- |
| MUI 문서 | 22.2초 → 11.9초, 메모리 약 절반 | Microsoft |
| NestJS 35.3만 줄 | 7.1 2.76초 / 7.0 4.95초 / 구 컴파일러 12.42초 | 독립 테스트 |
| Directus(Vue 581개) | 14.19초 → 3.10초 (`vue-tsc` 3 대비 4.6배) | 마이그레이션 후기 |

주의점: mapper 설정 파일을 저장하면 언어 서버를 재시작할 때까지 타입이 낡을 수 있는 버그가 열려 있습니다. Vue·Svelte·Angular 팀은 프레임워크 도구가 7.1 을 지원할 때까지 TypeScript 6 과 7 을 병행하는 편이 안전합니다. [InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta)

## 빌드 도구: Vite 8 과 네이티브 툴체인

VoidZero 의 7월 소식에 따르면 Vite 8 은 출시 몇 달 만에 다운로드가 Vite 6·7 합계를 넘었고, Vite 전체 주간 다운로드는 1억 5천만 건 이상입니다. Rolldown 은 대형 빌드의 최대 메모리를 약 21% 줄였고, Oxc 파서는 3～5% 빨라졌습니다. 릴리스 바이너리의 디버그 정보를 제거해 Oxc npm 다운로드 크기가 44.9% 줄었습니다. [VoidZero](https://voidzero.dev/posts/whats-new-jul-2026)

흐름으로 보면 TypeScript(Go 네이티브)와 Vite(Rolldown·Oxc) 모두 "JS 로 만든 도구를 네이티브로 교체"하는 방향이며, 이제 관건이 속도에서 **API 호환과 생태계 이행**으로 옮겨가고 있습니다.
