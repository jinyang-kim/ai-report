## 흐름: 최고 성능보다 용도별 적정 가격

[Analytics Vidhya 의 7월 정리](https://www.analyticsvidhya.com/blog/2026/07/july-2026-ai-models-releases/)는 Claude Opus 5(7월 24일)가 Fable 5 의 절반 가격($5／$25 대 $10／$50)에 근접한 성능을 낸다고 전하며, 경쟁의 초점이 "특정 작업에 맞는 모델을 적정 가격에"로 옮겨갔다고 분석합니다. GPT-5.6 은 Sol·Terra·Luna 3개 티어(입력 $5／$2.5／$1)로 나뉘어 출시됐고, 코딩 에이전트 벤치마크 우위에 대해서는 METR 이 벤치마크 조작 가능성을 제기해 논란이 있었다고 합니다. 10월 표에서도 Haiku 5.5 의 $0.10 입력가, DeepSeek-V4.1-Flash 의 $0.05 입력가처럼 저가 모델이 늘어난 점이 같은 흐름입니다.

실무 시사점은 세 가지입니다.

- 모델 라우팅(고난도 작업은 상위 티어, 반복 작업은 Flash·Haiku 급)이 비용 최적화의 기본 전략이 된다.
- 1M 컨텍스트가 보편화되어 컨텍스트 길이만으로는 차별점이 약해진다.
- 벤치마크 수치는 벤더 자체 발표와 제3자 검증이 갈리므로 자체 평가셋으로 재검증해야 한다.

## 언어·컴파일러: TypeScript 7 네이티브 전환

[State of TypeScript 2026](https://devnewsletter.com/p/state-of-typescript-2026/)은 Go 기반 컴파일러(코드명 Corsa)가 빌드 약 10배 가속을 목표로 한다고 정리합니다. 초기 벤치마크로 VS Code 코드베이스는 77.8초에서 7.5초, Playwright 는 11.1초에서 1.1초로 줄었다고 합니다. 이 글은 7.0 출시 시점을 확정하지 않은 기사이므로, 실제 릴리스 버전·날짜는 공식 릴리스 노트에서 확인하세요.

마이그레이션 시 점검할 변경점은 다음과 같습니다([같은 글](https://devnewsletter.com/p/state-of-typescript-2026/) 기준).

- `--strict` 가 기본값이 된다.
- ES5 타깃, AMD·UMD·SystemJS 출력, `node10` 모듈 해석, `baseUrl` 이 제거된다.
- 6.x 에서 deprecation 을 먼저 정리하고, 플러그인용 `tsc` 6.x 와 빌드용 `tsgo` 7.0 을 병행하는 전환 방식이 제안된다.
- 서드파티 도구의 새 컴파일러 API 호환성을 감사해야 한다.
