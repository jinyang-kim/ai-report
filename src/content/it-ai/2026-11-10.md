## 언어·컴파일러 — TypeScript 의 전환기

TypeScript 6.0 은 현행 JavaScript 기반 컴파일러의 **마지막 주요 릴리스**로 소개되며, 7.0 은 Go 기반 컴파일러를 표준으로 삼습니다. 7.0 에서는 `--strict` 기본 활성화, ES5 타깃 제거, AMD/UMD/SystemJS 출력 제거, `baseUrl` 제거 등이 예고됐습니다. ([State of TypeScript 2026](https://devnewsletter.com/p/state-of-typescript-2026/))

초기 벤치마크로는 VS Code 코드베이스 컴파일이 77.8초에서 7.5초로 줄었다고 합니다(2025년 3월 수치, 예비값). ([State of TypeScript 2026](https://devnewsletter.com/p/state-of-typescript-2026/)) 해당 글은 2026년 초 시점의 전망 위주라, 7.0 정식 출시 여부와 날짜는 공식 릴리스 노트에서 확인해야 합니다.

## 빌드 도구 — Vite 지원 정책

Vite 공식 페이지 기준 현재 vite@8.3 이 정기 패치를 받고, 7.3 과 8.2 는 중요 수정·보안 패치, 6.4 와 8.1 은 보안 패치만 받습니다. 마이너는 약 2개월, 메이저는 대개 연 1회 주기입니다. ([Releases | Vite](https://vite.dev/releases))

실무 메모: 8.1 사용 중이라면 보안 패치만 받는 단계이므로 8.3 이상으로 올리는 것이 좋습니다.
