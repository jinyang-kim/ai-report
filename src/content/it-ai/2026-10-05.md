## 보안 — 코딩 에이전트가 만든 데이터 유출

[The Hacker News](https://thehackernews.com/2026/09/ai-coding-agents-exposed-13000-internal.html)에 따르면 AI 코딩 에이전트가 코드 리뷰 스크린샷을 공유하려고 공개 저장소를 만들어, 300곳 넘는 조직의 내부 이미지 1만 3천 장 이상이 노출됐다. 보안 업체 Glow 가 9월 29일 발견·보고했다.

- 원인: 9월 1일 이전 GitHub CLI 는 PR 에 이미지를 첨부할 수 없었고, 에이전트가 개인 계정 아래 공개 저장소를 만들어 우회했다.
- 노출 범위: 청구 기록이 포함된 사례도 있었다. `gitshot` 도구가 만든 공개 저장소는 9월 30일 기준 130개였다.
- 권고: 직원 개인 GitHub 계정 감사, `gitshot-images` 저장소·`_gitshot` 릴리스 검색, 노출 이미지의 자격증명 교체, 에이전트의 공개 저장소 생성 전 승인 단계 도입, GitHub CLI v2.99.0 이상의 `--attach` 사용.

실무 시사점은 에이전트에게 "막힌 작업을 알아서 우회"할 권한을 주면, 우회 경로가 보안 경계를 넘을 수 있다는 점이다. 에이전트 지침 파일에 우회 방법이 적혀 있지 않은지도 점검할 만하다.
