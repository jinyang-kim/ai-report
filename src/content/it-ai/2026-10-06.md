## AI 모델 — 9월 말 플래그십 릴리스 러시

LLM Gateway 타임라인에 따르면 [2026년 9월에는 17개 제공사에서 27개 신규 모델이 출시됐다](https://llmgateway.io/timeline). 마지막 2주만 봐도 흐름이 빽빽하다.

| 날짜 | 모델 | 제공사 |
| --- | --- | --- |
| 9월 21일 | Grok 4.7 | xAI |
| 9월 22일 | Claude Opus 5.5 | Anthropic |
| 9월 22일 | GPT-6 Luna · GPT-6 Sol | OpenAI |
| 9월 28일 | Claude Sonnet 5.5 | Anthropic |
| 9월 29일 | GPT-6.1 Sol | OpenAI |

출처는 [LLM Gateway 타임라인](https://llmgateway.io/timeline)이다. 이 페이지에는 가격·벤치마크가 없어 이번 리포트에서는 성능·가격 비교를 하지 않는다. 같은 제공사가 GPT-6 Sol 에서 GPT-6.1 Sol 까지 일주일 만에 후속을 낸 점이 눈에 띈다. 모델 ID 를 고정하고 주기적으로 회귀 테스트를 돌리는 운영 방식이 필요해지고 있다.

## 개발 도구 — Copilot 이 CI 안쪽으로

- **코드 리뷰 API**: [Copilot 코드 리뷰를 REST·GraphQL API 로 요청하고 요청별로 effort 를 지정할 수 있다](https://github.blog/changelog/2026-10-02-copilot-code-review-api-support-and-new-default-effort-level). 기존 설정 "Default" 는 이제 "Balanced" 로 동작하며, 9월 28일부터 신규·기존 저장소에 적용됐다. Lite 를 선호하면 엔터프라이즈·조직·저장소·개인 단위에서 덮어쓸 수 있다.
- **VS Code 9월 릴리스**: [에이전트 창에서 시간·일·주 단위 반복 작업(automations)을 예약하고, 에이전트가 PR 병합을 돕는다](https://github.blog/changelog/2026-10-01-github-copilot-in-vs-code-september-2026-releases/). Dev Container 안에서 에이전트가 프로젝트 도구에 접근하는 기능과 이슈·PR URL 로 GitHub 맥락을 붙이는 기능도 들어갔다.
- **토큰 포맷**: [GitHub App 설치 토큰이 모두 stateless `ghs_APPID_JWT` 형식으로 발급된다](https://github.blog/changelog/2026-10-02-stateless-github-app-installation-tokens-rolled-out). 토큰 길이나 형식을 가정해 검증·저장하는 코드가 있다면 점검할 만하다.

## 일정 체크

- 10월 19일: 일부 Copilot 모델이 모든 Copilot 환경에서 폐기될 예정이다. 해당 모델에 의존하는 워크플로는 [GitHub 변경 로그](https://github.blog/changelog/2026-10-01-github-copilot-in-vs-code-september-2026-releases/)를 확인하고 미리 옮겨야 한다. 어떤 모델이 대상인지는 이번 조사에서 확인하지 못했다.
- 10월 15일: ViteConf 2026 이 온라인으로 열린다. Vite 8 은 [Rolldown 기반이며 Node.js 20.19+, 22.12+ 를 요구한다](https://vite.dev/blog/announcing-vite8).

## 시사점

모델은 주 단위로 갱신되고, 개발 도구는 사람이 호출하는 보조 기능에서 API·스케줄로 호출되는 자동화 단계로 옮겨가고 있다. 실무에서는 (1) 모델 교체에 대비한 평가 세트, (2) 리뷰·에이전트 호출의 비용 및 effort 정책, (3) 폐기 일정 추적이 먼저 필요하다.
