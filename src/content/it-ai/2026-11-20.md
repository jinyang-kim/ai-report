## 언어·컴파일러: TypeScript 7.1 베타

[InfoQ 보도](https://infoq.com/news/2026/11/typescript-7-1-beta)에 따르면 7.1 베타는 10월 20일에 공개됐고 예정보다 약 2주 늦었다.

- **컴파일러 API 복원**: 7.0 에서 빠졌던 프로그래밍 API 가 `typescript/sync`, `typescript/async`, `typescript/fs`, `typescript/ast` 진입점으로 돌아온다. 정식 이후 7.x 에서 하위 호환을 유지한다고 한다.
- **Content mapper**: `.vue`·`.svelte` 같은 비표준 파일을 TypeScript 가 가상으로 볼 수 있게 하는 플러그인 지점이다. Vue Language Tools v4 알파는 이를 이용해 `vue-tsc` 를 대체한다.
- **성능**: Directus 관리자 앱(Vue 컴포넌트 581개)의 타입 체크가 14.19초에서 3.10초로 줄어 `vue-tsc` 3 대비 4.6배 빠르다. 독립 테스트인 NestJS 프로젝트(35.3만 줄)는 12.42초(구 컴파일러), 4.95초(7.0), 2.76초(7.1 베타)였다.
- **언어 추가**: 앰비언트 모듈 선언의 import attributes, WebAssembly 용 source phase imports, `Math.sumPrecise()`·`Error.isError()` 를 포함한 안정 `es2026` 타깃이 들어간다.
- **알려진 문제**: mapper 가 감시하는 설정 파일을 저장하면 에디터에서 타입이 갱신되지 않는 이슈가 열려 있다.

RC 와 정식 출시는 11월 말로 잡혀 있으나 일정은 바뀔 수 있다. Vue·Svelte·Angular 프로젝트는 프레임워크 도구가 7.1 을 지원할 때까지 TypeScript 6 과 7 을 병행하라는 권고가 있다.
