## 언어·컴파일러: TypeScript 7.1 베타

Microsoft는 10월 20일 TypeScript 7.1 베타를 공개했다. 일정보다 2주 늦었고, 릴리스 후보와 안정판은 11월 말로 **잠정** 계획돼 있다. ([InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta))

- **컴파일러 API 복원**: 7.0에서 빠졌던 프로그래매틱 API가 `typescript/sync`, `typescript/async`, `typescript/fs`, `typescript/ast` 진입점으로 나뉘어 돌아왔고 `unstable` 접두어는 사라졌다. 안정판 이후 7.x 전반에서 하위 호환을 유지할 계획이다. ([InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta))
- **content mapper**: `.vue`·`.svelte` 같은 비표준 파일을 TypeScript에 가상 뷰로 보여 주고 원본 위치로 오류를 매핑하는 플러그인 지점이다. 별도 프로세스로 돌며 옵트인 시에만 실행된다. ([InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta))
- **언어 추가**: 앰비언트 모듈 선언의 import attributes, WebAssembly용 source phase imports, `Math.sumPrecise()`·`Error.isError()`를 포함한 안정 `es2026` 타깃. ([InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta))

| 벤치마크 | 이전 | 7.1 베타 |
| --- | --- | --- |
| Directus 관리자 앱(Vue, 타입 체크) | 14.19초 (vue-tsc 3) | 3.10초 |
| MUI 문서(Microsoft 측정) | 22.2초 | 11.9초 |
| NestJS 35.3만 줄(독립 테스트) | 4.95초 (7.0) | 2.76초 |

대형 코드베이스(VS Code)는 약 1.2배 수준이라 이득이 프로젝트마다 다르다. 같은 독립 테스트는 7.0의 메모리 회귀를 7.1이 되돌렸다고 지적했다. ([InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta))

**실무 시사점**: 도구 작성자는 새 진입점으로 이식을 시작하는 편이 좋다. Vue·Svelte·Angular 프로젝트는 프레임워크 도구가 7.1을 지원할 때까지 TypeScript 6과 7을 병행하고, CI에서만 7.1을 돌리는 방식이 제안됐다. 알려진 이슈로 mapper가 감시하는 설정 파일을 저장한 뒤 타입이 갱신되지 않는 문제(#65084)가 열려 있다. ([InfoQ](https://infoq.com/news/2026/11/typescript-7-1-beta))
