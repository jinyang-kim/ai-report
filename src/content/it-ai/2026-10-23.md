## 언어·컴파일러: TypeScript 7 의 네이티브 전환

React 커뮤니티 주간 팟캐스트는 "TypeScript 7 is finally live" 라며, 최신 `typescript` 패키지를 설치하면 내부가 Go 로 만들어진 빌드를 받게 된다고 전했습니다. 기존보다 최대 10배 빠르다는 것이 취지입니다 ([TMiR 2026-07](https://tmir.reactiflux.com/episodes/2026-07)).

가장 큰 주의점은 프로그래밍 API 입니다. 같은 방송은 "the programmatic TypeScript API essentially does not exist in version seven" 이라고 했고, 제대로 된 공개 API 설계 후 7.1 또는 7.2 에서 제공할 계획이라고 전했습니다 ([TMiR 2026-07](https://tmir.reactiflux.com/episodes/2026-07)). 컴파일러 API 에 기대던 린터·번들러 플러그인·코드 생성 도구는 영향을 받습니다.

출시 전 정리 글 기준으로 알려진 내용은 다음과 같습니다 ([State of TypeScript 2026](https://devnewsletter.com/p/state-of-typescript-2026/)). 이 글은 출시 전에 쓰인 것이라 수치는 초기 벤치마크로 봐야 합니다.

| 항목 | 내용 |
| --- | --- |
| VS Code 빌드 시간 | 77.8초 → 7.5초 |
| Playwright 빌드 시간 | 11.1초 → 1.1초 |
| 메모리 | 약 50% 감소 |
| 기본값·제거 | `--strict` 기본 활성, `--target ES5`·AMD/UMD/SystemJS·`baseUrl` 제거 |

실무 권고는 CI 에서 먼저 7.0 을 시험하고, 플러그인이 필요한 곳은 6.x 와 `tsgo` 를 병행하는 하이브리드 구성을 검토하는 것입니다 ([State of TypeScript 2026](https://devnewsletter.com/p/state-of-typescript-2026/)).

## 빌드 도구: Vite 8, Rolldown, Oxc

VoidZero 7월 소식에 따르면 Vite 8 의 다운로드 수는 출시 몇 달 만에 Vite 6 과 7 의 합계를 넘었습니다. Rolldown 은 대형 빌드의 최대 메모리를 약 21% 줄였고, Vitest 5 는 베타(5.0.0-beta.7)에서 속도 개선과 Temporal 객체 모킹을 추가했습니다 ([VoidZero](https://voidzero.dev/posts/whats-new-jul-2026)).

Oxc 쪽에서는 타입 인식 린팅(tsgolint)이 안정화됐고 특정 TypeScript 릴리스에 버전이 묶입니다. 파서는 3～5% 빨라졌습니다 ([VoidZero](https://voidzero.dev/posts/whats-new-jul-2026)). 온라인 컨퍼런스 ViteConf 는 10월 15일에 열렸습니다 ([VoidZero](https://voidzero.dev/posts/whats-new-jul-2026)).

> 컴파일러·번들러·린터가 모두 네이티브로 옮겨가고, 확장 지점(API)이 그 뒤를 따라오는 순서가 올해 JS 툴체인의 패턴입니다.
