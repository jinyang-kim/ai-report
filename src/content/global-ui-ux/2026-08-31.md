> 첫 실제 리포트가 들어오면 `src/content/global-ui-ux/2026-08-31.md`를 삭제하세요.

## 1. 디자인 트렌드

신규 비주얼·인터랙션 패턴, 제품 리디자인, 디자인 시스템 업데이트를 다룹니다. 날짜가 명시된
공식 릴리스만 인용하고, 날짜 없는 체인지로그는 "확인 불가"로 처리합니다.

## 2. UX 문제 사례

실제 UX 실패, 다크패턴, 접근성 이슈를 **원인과 대안을 함께** 씁니다. 다크패턴은 대체로
악의가 아니라 KPI의 산물이라는 관점을 유지합니다 — 전환율 지표만 최적화하면 취소 흐름이
저절로 나빠집니다.

## 3. 수치·리서치 데이터

정량 지표에는 예외 없이 출처·측정 시점·표본과 방법론을 붙입니다.

| 지표 | 값 | 출처 | 측정 시점 | 표본 |
| --- | --- | --- | --- | --- |
| (예시 행) | — | — | — | — |

숫자를 만들어내지 않는 것이 이 섹션의 유일한 규칙입니다.

## 4. 프론트엔드 구현

그날의 내용을 Vue 3 `script setup` / React / CSS로 어떻게 적용하는지 짧고 정확한 코드로
보여줍니다.

```css
/* 라이트·다크를 한 줄로 — light-dark() 는 Baseline 2024-05 */
.card {
  background: light-dark(#fcfcfb, #1a1a19);
  color: light-dark(#0b0b0b, #ffffff);
}
```
