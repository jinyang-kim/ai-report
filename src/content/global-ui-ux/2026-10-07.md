## 접근성

WebAIM Million 2026 분석은 홈페이지 100만 개에서 5,600만 건이 넘는 오류를 찾았고, 페이지당 평균은 56.1건으로 전년보다 10.1% 늘었습니다. [출처](https://prioritypixels.co.uk/insights/web-accessibility-is-getting-worse-according-to-the-2026-webaim-million-report/) WCAG 2 실패가 감지된 홈페이지 비율도 94.8%에서 95.9%로 올라, 점진적으로 개선되던 흐름이 뒤집혔습니다. 같은 글은 페이지당 평균 요소 수가 1,437개로 1년 새 22.5% 늘어난 복잡도 증가를 한 배경으로 듭니다.

| --- | --- |
| 낮은 대비 텍스트 | 83.9% |
| 이미지 대체 텍스트 누락 | 53.1% |
| 폼 입력 레이블 누락 | 51% |
| 텍스트 없는 링크 | 46.3% |
| 텍스트 없는 버튼 | 30.6% |

([출처](https://prioritypixels.co.uk/insights/web-accessibility-is-getting-worse-according-to-the-2026-webaim-million-report/))

ARIA 사용은 1년 새 27% 늘어 2019년의 6배 수준이지만, ARIA 가 있는 페이지의 평균 오류는 59.1건으로 없는 페이지(42건)보다 많았습니다. [출처](https://prioritypixels.co.uk/insights/web-accessibility-is-getting-worse-according-to-the-2026-webaim-million-report/) 상관관계일 뿐 인과를 증명하진 않지만, 네이티브 HTML 로 해결되는 곳에 ARIA 를 덧대는 것이 능사가 아님을 시사합니다. 또 이 수치는 자동 검사로 잡히는 오류만 센 것이라 실제 사용성 문제는 더 많을 수 있습니다. 플랫폼별로는 WordPress 52.8건, Shopify 75.1건, Magento 75.8건이었습니다.

## 성능

CrUX 기준 2026년 1월 전체 웹 오리진의 55.7%가 Core Web Vitals 세 지표를 모두 통과합니다. [출처](https://www.shno.co/marketing-statistics/core-web-vitals-statistics) 같은 출처에는 INP 200ms 기준을 못 넘는 사이트가 43%라는 수치도 있는데, 다른 집계(2026년 1월 CrUX 오리진의 87.1%가 INP 양호)와 차이가 큽니다. 집계 방식(오리진·URL, 모바일·데스크톱)에 따라 달라지므로 비교할 땐 기준을 맞춰야 합니다. 디바이스별 분포는 [INP distribution](https://www.corewebvitals.io/state-of-cwv/explorer/cwv/inp)에서 볼 수 있습니다. 이 수치들은 2차 집계 사이트의 것이라, 실제 의사결정엔 CrUX 원데이터로 확인하길 권합니다.

## 기술 표준

W3C 는 2026년 3월 3일 WCAG 3 작업 초안을 공개하고 GitHub·이메일로 의견을 받고 있습니다. [출처](https://www.w3.org/WAI/news/2026-03-03/wcag3) 2차 해설에 따르면 이 초안은 Bronze·Silver·Gold 적합성 단계를 두고, Bronze 가 대체로 WCAG 2.2 AA 에 해당합니다. 최종 발행 시점은 확정되지 않았습니다. [출처](https://www.webability.io/blog/wcag-3-0-explained) 따라서 법적·계약상 기준은 당분간 WCAG 2.x 로 보는 것이 안전합니다.

## 오늘 바로 적용할 것

- 텍스트 대비를 먼저 점검하세요. 가장 흔한 오류(83.9%)이고 디자인 토큰 한 곳에서 고칠 수 있습니다.
- 아이콘 버튼·아이콘 링크에 접근 가능한 이름이 있는지, `<html lang>` 이 있는지 확인하세요.
- ARIA 를 추가하기 전에 네이티브 요소(`button`, `label`, `a`)로 해결되는지 먼저 보세요.
- 자동 검사 통과를 접근성 완료로 보지 말고 키보드·스크린리더 수동 점검을 병행하세요.
- 성능 지표는 모바일 기준 INP 를 따로 모니터링하세요.
