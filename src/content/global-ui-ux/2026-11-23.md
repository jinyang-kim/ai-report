## 접근성

[WebAIM Million 2026](https://webaim.org/projects/million/)에 따르면 상위 100만 홈페이지의 **95.9%** 에서 WCAG 2 위반이 자동 검사로 검출됐습니다(2025년 94.8%). 페이지당 평균 오류는 **56.1개**로 전년의 51개보다 10.1% 늘었고, 전체 요소의 3.9%(약 26개 중 1개)에 오류가 있었습니다. 그동안 조금씩 나아지던 추세가 꺾였다는 점이 이번 보고서의 특징입니다.

| 오류 유형 | 해당 홈페이지 비율 |
| --- | --- |
| 낮은 텍스트 대비 | 83.9% |
| 이미지 대체 텍스트 누락 | 53.1% |
| 폼 입력 레이블 누락 | 51% |
| 빈 링크 | 46.3% |
| 빈 버튼 | 30.6% |
| 문서 언어 누락 | 13.5% |

위 여섯 유형이 검출 오류의 96%를 차지합니다([WebAIM](https://webaim.org/projects/million/)). 즉 대부분은 새로운 문제가 아니라 대비·레이블·alt 같은 기본기 문제입니다. 한계도 있습니다. 자동 검사는 홈페이지만 대상으로 하고 검출 가능한 오류만 세므로, 키보드 흐름이나 스크린리더 사용성 같은 실제 장벽은 이 수치에 잡히지 않습니다.

## 기술 표준

W3C 는 [WCAG 3 작업 초안을 2026년 3월 3일에 검토용으로 갱신](https://www.w3.org/WAI/news/2026-03-03/wcag3)했고, 이후 9월에도 갱신 초안이 공지된 것으로 확인됩니다(9월 초안 본문은 열어보지 못했습니다). [WCAG 3 초안](https://www.w3.org/TR/wcag30/)은 여전히 W3C 의 승인을 의미하지 않는 미완성 작업 초안이며, W3C 는 WCAG 3 가 WCAG 2 를 폐기하지 않는다고 밝힙니다. 따라서 규정 준수 기준은 당분간 WCAG 2.2 입니다. 완료 시점에 대한 구체적 일정 추정은 제3자 의견이라 여기서는 다루지 않습니다.

## 성능

[Web Almanac 2025 성능 장](https://almanac.httparchive.org/en/2025/performance)에 따르면 모바일 Core Web Vitals 통과율은 2023년 36%, 2024년 44%, 2025년 48%로 꾸준히 올랐습니다. 다만 소프트 내비게이션(SPA 전환)은 현재 웹 바이탈 측정에 완전히 반영되지 않는다고 지적합니다. 2026년 CrUX 통과율을 제시하는 블로그 수치들은 1차 출처로 확인하지 못해 인용하지 않습니다.

## 오늘 바로 적용할 것

- 텍스트·배경 대비를 디자인 토큰 단위로 점검합니다(WCAG AA 4.5:1). 오류 1위가 대비입니다.
- 아이콘 전용 링크·버튼에 접근 가능한 이름(`aria-label` 또는 시각적 숨김 텍스트)이 있는지 확인합니다. 빈 링크·빈 버튼이 각각 46.3%, 30.6%입니다.
- 모든 폼 입력에 `<label>` 을 연결하고, `<html lang>` 을 지정합니다.
- 자동 검사 통과를 끝으로 보지 말고 키보드·스크린리더 수동 점검을 병행합니다.
- 규정 대응 문서는 WCAG 2.2 기준으로 유지하고 WCAG 3 는 모니터링만 합니다.
