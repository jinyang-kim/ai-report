## 접근성

2026 WebAIM Million 분석에 따르면 홈페이지의 95.9%에서 WCAG 2 위반이 검출돼 2025년의 94.8%보다 늘었고, 페이지당 평균 오류는 56.1개로 10.1% 증가했습니다. [Priority Pixels 요약](https://prioritypixels.co.uk/insights/web-accessibility-is-getting-worse-according-to-the-2026-webaim-million-report/)

페이지 복잡도가 한 원인으로 지목됩니다. 평균 요소 수는 1,437개로 1년 새 22.5% 늘었고, 장애가 있는 사용자는 대략 26개 요소마다 오류를 만나는 셈입니다. [Priority Pixels](https://prioritypixels.co.uk/insights/web-accessibility-is-getting-worse-according-to-the-2026-webaim-million-report/)

| 오류 유형 | 해당 페이지 비율 |
| --- | --- |
| 저대비 텍스트 | 83.9% |
| 이미지 대체텍스트 누락 | 53.1% |
| 폼 입력 라벨 누락 | 51% |
| 빈 링크 | 46.3% |
| 빈 버튼 | 30.6% |
| 문서 언어 선언 누락 | 13.5% |

이 여섯 유형이 검출 오류의 96%를 차지하며 7년째 같은 순위권입니다. ARIA 를 쓴 페이지는 평균 59.1개 오류로, 쓰지 않은 페이지(42개)보다 많았습니다. 다만 이는 상관관계이며 ARIA 자체가 원인이라는 뜻은 아닙니다. [Priority Pixels](https://prioritypixels.co.uk/insights/web-accessibility-is-getting-worse-according-to-the-2026-webaim-million-report/)

**한계**: 자동 검사는 이슈 일부만 잡으므로 실제 비준수율은 더 높을 가능성이 큽니다. 또 일부 해설자는 실패율 상승을 통계적 변동 범위로 보기도 합니다.

## 성능

2차 자료(블로그·통계 모음)에 따르면 2026년 1월 CrUX 기준 양호 비율은 LCP 68.3%, INP 87.1%, CLS 80.9%로, INP 가 가장 많이 통과하는 지표로 보입니다. INP 기준은 75퍼센타일 기준 200ms 이하가 양호, 500ms 초과가 불량입니다. [Core Web Vitals statistics](https://www.shno.co/marketing-statistics/core-web-vitals-statistics)

**주의**: 이 수치는 Google·HTTP Archive 1차 자료로 직접 확인하지 못했고, 출처마다 통과율이 다릅니다(전체 통과 55.7%라는 분석도 있음). 의사결정 전 CrUX 대시보드나 Web Almanac 에서 직접 확인하세요.

## 기술 표준

W3C WAI 는 2026년 3월 3일 WCAG 3 작업 초안(Working Draft) 갱신본을 공개하고 의견을 받고 있습니다. [W3C WAI 공지](https://www.w3.org/WAI/news/2026-03-03/wcag3) 2차 해설에 따르면 이 초안은 Bronze·Silver·Gold 3단계 적합성 모델을 제안하며, 후보 권고안은 빨라야 2027년 말로 예상됩니다. 이 일정은 W3C 공식 확인이 아닌 2차 자료 기준입니다. 법적·계약상 준수 기준은 당분간 WCAG 2.2 입니다.

## 오늘 바로 적용할 것

- 텍스트·배경 대비를 점검하세요. 가장 흔한 오류(83.9%)이며 디자인 토큰 단계에서 고치면 전체에 반영됩니다.
- 모든 `<img>` 의 `alt`, 폼 컨트롤 라벨, 아이콘 전용 링크·버튼의 접근 가능한 이름을 CI 린트로 검사하세요.
- ARIA 는 네이티브 HTML 로 해결되지 않을 때만 쓰세요.
- 자동 검사 통과를 접근성 완료로 간주하지 말고, 키보드와 스크린리더 수동 점검을 병행하세요.
- WCAG 3 는 모니터링만 하고, 현재 목표는 WCAG 2.2 AA 로 유지하세요.
