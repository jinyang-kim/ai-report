## 접근성: 2026 WebAIM Million 이 보여준 악화

상위 100만 개 홈페이지를 자동 검사한 2026 WebAIM Million 에서 **95.9%** 가 감지 가능한 WCAG 2 실패를 보였고(2025년 94.8%), 페이지당 평균 오류는 **56.1개**로 10.1% 늘었습니다. [Priority Pixels 의 보고서 정리](https://prioritypixels.co.uk/insights/web-accessibility-is-getting-worse-according-to-the-2026-webaim-million-report/)

오류의 96%는 매년 같은 여섯 유형입니다.

| 오류 유형 | 해당 홈페이지 비율 |
| --- | --- |
| 저대비 텍스트 | 83.9% (전년 79.1%) |
| 이미지 대체 텍스트 누락 | 53.1% |
| 폼 입력 레이블 누락 | 51% |
| 빈 링크 | 46.3% |
| 빈 버튼 | 30.6% |
| 문서 언어 선언 누락 | 13.5% |

출처: [Priority Pixels](https://prioritypixels.co.uk/insights/web-accessibility-is-getting-worse-according-to-the-2026-webaim-million-report/)

- ARIA 사용은 1년간 27% 늘었지만, ARIA 를 쓴 페이지는 평균 59.1개 오류로 쓰지 않은 페이지(42개)보다 많았습니다. [Priority Pixels](https://prioritypixels.co.uk/insights/web-accessibility-is-getting-worse-according-to-the-2026-webaim-million-report/)
- 한계: 자동 검사는 문제의 일부만 잡으므로 실제 비적합 비율은 더 높을 가능성이 큽니다. 또 ARIA 와 오류의 관계는 상관이지 인과가 아닙니다(복잡한 페이지일수록 ARIA 를 더 쓰는 영향 가능).

## 기술 표준: WCAG 3.0 은 아직 작업 초안

W3C 는 2026년 3월 3일 WCAG 3.0 작업 초안을 "검토용"으로 갱신했고 의견은 wai@w3.org 메일링 리스트나 GitHub 이슈로 받습니다. 변경 내용은 해당 공지가 아니라 WCAG 3 소개 문서의 상태 섹션에서 확인하게 되어 있습니다. [W3C WAI 공지](https://www.w3.org/WAI/news/2026-03-03/wcag3), [WCAG 3.0 초안](https://www.w3.org/TR/WCAG30/)

- 2차 매체는 3월 초안에서 "Foundational Requirements"가 "Core Requirements"로 바뀌고 Bronze·Silver·Gold 등급이 복원됐다고 전하지만, 이는 W3C 원문으로 직접 확인하지 못한 내용입니다.
- 이 외 일부 페이지가 9월 날짜 버전을 표시하나 공지·변경 이력을 확인하지 못했습니다.
- 법규 준수 기준으로는 WCAG 2.2 를 계속 쓰는 것이 안전합니다.

## 성능: Core Web Vitals 완만한 개선

INP 는 2024년 3월 FID 를 대체했으며 기준은 75번째 백분위 200ms 미만(양호), 500ms 초과(불량)입니다. 순위 신호는 Lighthouse 가 아닌 CrUX 필드 데이터(28일 롤링)를 씁니다. [anim.hr](https://anim.hr/en/blog/core-web-vitals-2026)

- 2차 인용에 따르면 2025 Web Almanac 기준 모바일 통과율은 2023년 36%에서 2025년 48%, 데스크톱은 56%입니다.
- 주의: 위 수치는 SEO 업체 블로그의 재인용이며 Web Almanac·CrUX 원문을 확인하지 못했습니다. 방향성 참고용으로만 보세요.

## 오늘 바로 적용할 것

1. **대비 점검**: 가장 흔한 실패(83.9%)이므로 디자인 토큰 단위로 4.5:1(본문)·3:1(큰 글자·UI) 자동 검사를 CI 에 넣습니다.
2. **레이블·이름 점검**: 폼 입력, 아이콘 버튼, 아이콘 링크에 접근 가능한 이름이 있는지 확인합니다.
3. **ARIA 줄이기**: `div` + `role` 대신 네이티브 `button`·`a`·`label` 을 우선 씁니다.
4. **필드 데이터 보기**: INP 는 Lighthouse 가 아닌 CrUX 필드 값으로 추적합니다.
5. **WCAG 3.0 은 관찰만**: 개정 초안 흐름은 지켜보되 준수 목표는 2.2 AA 로 유지합니다.
