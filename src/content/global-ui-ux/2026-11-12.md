## 접근성

[WebAIM Million](https://webaim.org/projects/million/)의 2026년 2월 분석에 따르면 상위 100만 개 홈페이지의 95.9%에서 WCAG 2 위반이 자동 검출됐다(2025년 94.8%). 페이지당 평균 오류는 56.1개로 전년 51개보다 약 10% 늘었다.

| 오류 유형 | 홈페이지 비율 |
| --- | --- |
| 저대비 텍스트 | 83.9% |
| 이미지 대체 텍스트 누락 | 53.1% |
| 폼 입력 레이블 누락 | 51% |
| 빈 링크 | 46.3% |
| 빈 버튼 | 30.6% |
| 문서 언어 누락 | 13.5% |

출처: [WebAIM Million](https://webaim.org/projects/million/)

ARIA 사용도 늘었다. [ARIA를 쓰는 홈페이지가 82.7%](https://webaim.org/projects/million/)(2025년 79.4%)이고, 페이지당 ARIA 속성은 평균 133개 이상으로 27% 증가했다. 다만 ARIA를 쓴 페이지의 평균 오류는 59.1개로, 쓰지 않은 페이지(42개)보다 많았다. ARIA가 오류의 원인이라고 단정할 수는 없다. 복잡한 페이지일수록 ARIA도 많이 쓰는 상관관계일 수 있다.

한계: 이 조사는 자동 검사 도구가 잡는 홈페이지 오류만 센다. 스크린리더 실사용성이나 키보드 흐름 같은 수동 검증 항목은 포함하지 않으며, 하위 페이지도 다루지 않는다.

## 성능

[2025 Web Almanac 성능 장](https://almanac.httparchive.org/en/2025/performance)(2025년 7월 데이터)의 Core Web Vitals 통과율은 모바일 48%(2024년 44%), 데스크톱 56%(55%)다.

| 지표 | 모바일 양호 | 데스크톱 양호 |
| --- | --- | --- |
| LCP | 62% | 74% |
| INP | 77% | 97% |
| CLS | 81% | 72% |

출처: [Web Almanac 2025: Performance](https://almanac.httparchive.org/en/2025/performance)

- 모바일 INP 양호 비율은 74%에서 77%로 올랐고, 모바일과 데스크톱의 격차는 23%p에서 20%p로 줄었다. 상위 1,000개 모바일 사이트의 INP 양호 비율은 53%에서 63%로 올랐다.
- 반면 모바일 중간 TBT(Total Blocking Time)는 58% 늘어 1,916ms가 됐다. [JavaScript 실행 부담이 오히려 커졌다](https://almanac.httparchive.org/en/2025/performance)는 신호다.
- 모바일 페이지의 62%에 크기 속성이 없는 이미지가 하나 이상 있어, CLS 악화의 흔한 원인으로 남아 있다.

한계: 이 수치는 2025년 7월 CrUX 기준이라 현재 상황과 차이가 있을 수 있다. 2026년 수치를 내놓는 2차 사이트들은 이번 조사에서 1차 출처로 확인하지 못해 인용하지 않았다.

## 기술 표준

W3C는 2026년 3월 3일 [WCAG 3 작업 초안을 검토용으로 공개](https://www.w3.org/WAI/news/2026-03-03/wcag3)했다. 작업 초안은 완성된 표준이 아니며, W3C는 이메일(wai@w3.org)과 GitHub 이슈로 의견을 받는다. 의견은 공개 보관된다. 초안 이후 새 버전이 나왔다는 주장은 W3C 페이지로 확인하지 못했으므로 다루지 않는다. 컴플라이언스 대응은 계속 WCAG 2.x(2.2)를 기준으로 하면 된다.

## 오늘 바로 적용할 것

- 홈페이지에서 저대비 텍스트, 이미지 `alt`, 폼 `label`, 빈 링크·버튼, `<html lang>` 여섯 항목부터 점검한다. 모두 위 표의 상위 오류다.
- ARIA를 추가하기 전에 네이티브 HTML 요소로 해결되는지 확인한다.
- 이미지와 영상에 `width`·`height`를 지정해 CLS를 줄이고, 모바일에서 긴 작업을 쪼개 TBT·INP를 점검한다.
- 자동 검사 통과를 접근성 완료로 보지 말고, 키보드와 스크린리더 수동 점검을 병행한다.
